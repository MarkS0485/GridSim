# GridSim brand kit - v1

Social / visual identity for GridSim, drawn from the product's own control-room
palette (`src/GridSim.Wpf/Visuals/Palette.cs`) - **not** the TSGB red/white/blue.

Open **`brand-kit.html`** in a browser for the full board (avatars, header, wordmark,
palette, specs).

## Assets

| File | Size | Use |
|---|---|---|
| `avatar-nadir.svg` | 400x400 | Profile avatar - **Concept A "Nadir"**: the frequency trace holding above the amber LFDD floor. Recommended; reads at 48 px. |
| `avatar-node.svg` | 400x400 | Profile avatar - **Concept B "Node"**: tube-map network with a green slack bus. |
| `header.svg` | 1500x500 | X / Twitter header banner. Text sits in the centre-safe band; bottom-left avatar overlap and mobile side-crop kept clear. |
| `brand-kit.html` | - | The presentation board / spec sheet. |

Export to PNG at the native sizes (open an SVG in a browser and export/screenshot,
or use any SVG->PNG tool).

- The HTML preview uses system stacks because it inlines no webfonts.
