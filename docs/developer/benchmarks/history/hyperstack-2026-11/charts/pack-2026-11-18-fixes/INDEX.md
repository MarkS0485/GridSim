Sources (read-only): GridSim paths from `$GRIDSIM_BENCH_ROOT/hyperstack-3-canada-2026-11-18/bench-runs/full-cand-20261118T0918Z/comparison.csv` (hyperstack-3 full-cand, EPYC 7763 28 vCPU); other solvers from `$GRIDSIM_BENCH_ROOT/hyperstack-3-canada-2026-11-18/bench-runs/focused-others-20261118T1033Z/comparison.csv` (same box, 16 focused cases) and, for the remaining cases, `$GRIDSIM_BENCH_ROOT/hyperstack-2-canada-2026-11-17/suite-full-20261117T2356Z/comparison.csv` (hyperstack-2, same CPU class), because the hyperstack-3 full runs measured GridSim dense/sparse only. Before/after charts: focused base rounds 3 x / cand rounds 3 x under `$GRIDSIM_BENCH_ROOT/hyperstack-3-canada-2026-11-18/bench-runs`, and full-base `$GRIDSIM_BENCH_ROOT/hyperstack-3-canada-2026-11-18/bench-runs/full-base-20261118T1004Z/comparison.csv`. Method: one core, Release, tiered JIT off, mean of 10 timed solves, solve time only, flat start, 67 MATPOWER 8.1 cases. Accuracy gate: status complete, converged 10, max residual <= 1e-8 pu. Win/tie/loss: sparse vs fastest accurate other solver, 10% tie band.

Scorecard here: 62 wins / 0 ties / 0 losses / 5 nobody solved. Old box 2 (RC-3): 54 / 3 / 5 / 5.

Headline tone is deliberately loud; every number comes from the data and the small print states hardware, method and gate. Squares are 1080x1080.
