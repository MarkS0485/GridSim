# 13. Asset-dynamics data grounding

This chapter is the provenance ledger for the authored asset classes: for each class kind and each parameter in the
bundled `asset-classes.json` files, it says whether the value is grounded in a recorded source (`Recorded` or
`DerivedFromRecorded`) or is a literature-approximated placeholder (`CuratedPlaceholder` carrying the literal token
`[VERIFY]`). It states the sources with their exact values (EREC G99, EREC G59, the Grid Code, NESO services, the GDA
lake), how the loader validates the classes and refuses malformed ones (`AssetClass.ValidateProvenance`,
`AssetClassSupport.Problems`), and how each parameter reaches a controller in `src/GridSim.Core/Assets`. It ends with
a worked example that follows one parameter from the file to a captured trip run.

The bundled files are `data/gb-full/asset-classes.json` (7 classes, generated by GDA), and
`data/gb-synthetic/asset-classes.json` (8 classes, hand-authored, with `data/gb-synthetic/protections.json` placing the
two protection classes). No other bundled case carries asset classes. The class schema is `gridsim-asset-classes/1`
(`src/GridSim.Core/IO/Json/AssetClassDto.cs`). The dynamics the classes drive are specified in
[ch. 5, Frequency dynamics](<0005 Frequency dynamics.md>); the protection stages in
[ch. 15, Protections](<0015 Protections.md>); the cascade validation in
[ch. 14, Cascade validation and blind prediction](<0014 Cascade validation and blind prediction.md>).

## Model

### Provenance tags

Every parameter of an authored class has one provenance tag (`ProvenanceTag`, `src/GridSim.Core/Diagnostics/Provenance.cs`).
Three tags occur in the bundled asset classes, and the loader accepts any `ProvenanceTag` name. A fourth tag,
`UnvalidatedAtScale`, tags fleet-level results:

| Tag | Meaning in an asset class | Note must contain `[VERIFY]` |
|---|---|---|
| `Recorded` | A published setting or recorded fact, cited by document, table and page, or by GDA source file | no |
| `DerivedFromRecorded` | Computed from recorded data (a ratio, a median, a coincident block) | no |
| `CuratedPlaceholder` | Stands in for data that is not available; vendor-proprietary or absent from every source | yes |
| `UnvalidatedAtScale` | A fleet-level result whose absolute value at GB scale has no reference | not applicable |

`Synthetic`, `Counterfactual` and `Interpolated` are valid tags for evidence series
([ch. 7](<0007 The evidence engine.md>)) but are not used by asset classes. `UnvalidatedAtScale` tags a result, not a
parameter: the 2019-08-09 cascade reproduction is tagged `UnvalidatedAtScale` because its depth depends on the
embedded-generation volume that tripped, which no source records.

A class lists its provenance as a block of `parameter -> { tag, note }` entries. `AssetClass.ProvenanceFor(key)`
resolves a parameter in this order:

1. the entry named for the parameter;
2. the entry named `_default`;
3. a synthetic `CuratedPlaceholder` with the note `[VERIFY] unspecified provenance`.

A parameter with no entry of its own therefore inherits the class `_default`, which is a `CuratedPlaceholder` in every
bundled class that has one. The two protection classes in `gb-synthetic` have no `_default`: a parameter they do not
list (`rocofTripConfirmS` of `prot-lom-legacy`, `lfddDwellS` of `prot-lfdd-stage1`) resolves to the synthetic
placeholder.

### Files and binding

| File | Content | Loader |
|---|---|---|
| `asset-classes.json` | The class library: name, kind, mode, `params` (flat name to number), `provenance` | `JsonGridLoader.BuildLibrary` |
| `asset-bindings.json` | Rules `matchType` -> `class`: bind every generator, transformer or line whose type matches | `JsonGridLoader.BuildAssetDynamics` |
| `protections.json` | Placed protection instances (`name`, `class`, `monitorBus`, `capacityMw`, optional `targetBranch`) | `JsonGridLoader.BuildProtections` |

`AssetBindingSet.Resolve` binds in this order: the asset's own `dynamicsClass`; the first exact `matchType`
(case-insensitive); the first prefix wildcard (`wind*` matches `wind-onshore` and `wind-offshore`). An asset that
matches nothing stays passive. The bundled rules:

| Dataset | Rules |
|---|---|
| `gb-full` | `wind*` and `tidal` -> `gfl-wind-2024`; `solar` -> `gfl-solar-2024`; `storage` -> `gfm-bess-2024`; `interconnector` -> `hvdc-2024`; `transformer` -> `tx-oltc-2024`; `line` -> `cable-thermal-2024` |
| `gb-synthetic` | `onshore`, `offshore` and `wind` -> `gfl-wind-2024`; `solar` -> `gfl-solar-2024`; `storage` -> `gfm-bess-2024` |

Synchronous plant (in `gb-full`: ccgt, ocgt, gas, chp, biomass, hydro, nuclear, recip, pumped-storage, grid, other)
matches no rule and stays passive: it carries no inverter loop. In `gb-synthetic` the ten `interconnector` units also
match no rule and stay passive. `legacy-dg-old-lom`, `dg-alomcp` and `gfm-vsm-study-2024` have no
bulk rule; a generator reaches them through its own `dynamicsClass`, and `gfm-vsm-study-2024` is the class the `h0-study`
verb substitutes.

### What the loader validates

`JsonGridLoader.LoadDirectory` builds the class library with the checks below. Every check fails loud with
`InvalidDataException`. Steps 1 and 2 run class by class while the library is built (for each class its provenance
tags are parsed first, then its kind), and a duplicate name (step 3) throws when it is reached; the first such error
stops the load. Then the problems collected in step 3 are thrown together, then the provenance check of step 4.

1. Each class kind must be one of the spellings above (`ParseAssetKind`): otherwise `asset class '<name>' has unknown kind '<s>'`.
2. Each provenance tag must parse as a `ProvenanceTag` name, ignoring case (`ParseProvenanceTag`): otherwise `asset class '<name>' parameter '<key>' has unknown provenance tag '<s>'`.
3. `AssetClassLibrary` construction refuses a duplicate class name (case-insensitive) and collects every problem from `AssetClassSupport.Problems` into one exception headed `Unsupported asset class input`: a class of an unsupported kind (`synchronousMachine`), a refused key, a key no consumer of the kind reads.
4. `AssetClassLibrary.ValidateOrThrow` runs `AssetClass.ValidateProvenance` on every class and lists every violation in one exception headed `Invalid asset-classes.json`. `ValidateProvenance` reports each provenance entry (explicit or `_default`) that is `CuratedPlaceholder` and whose note lacks the literal `[VERIFY]`.
5. `asset-bindings.json` is refused when it is present and `asset-classes.json` defines no classes, and when a rule names a class that does not exist.
6. `protections.json` is refused when `asset-classes.json` defines no classes, when an instance names an unknown class, and when the named class is not of kind `protection`.

A class built in code and passed to `new AssetClassLibrary(...)` meets steps 3 only; `ValidateOrThrow` is a separate
call. The loader makes both calls.

`ValidateProvenance` checks the entries a class lists. It cannot require an entry for a parameter, so the rule that a
`Recorded` or `DerivedFromRecorded` tag is true is enforced by review, not by code. Two tests pin the citation text
of three values: the legacy vector-shift setting, and the `dg-alomcp` RoCoF threshold and delay. The legacy
0.125 Hz/s and the 48.8 Hz LFDD citations are pinned by no test.

### Protection (`ProtectionController.BuildStages`)

A class produces one stage per key present. `Trip` stages latch and remove `capacityMw` of infeed once; in a recloser
class (one that sets `autoRecloseDelayS`) every trip stage instead opens `targetBranch` and recloses after the delay.

Three rules apply before any stage is built:

- **Dwells are required.** A class that sets a threshold must set its dwell (`AssetParamDefaults.ProtectionDwellKeys`:
  `rocofTripConfirmS`, `dfDtTripDwellS`, `ufTripDwellS`, `ofTripDwellS`, `uvTripDwellS`, `ovTripDwellS`,
  `overloadTripDwellS`, `lfddDwellS`). `0` is a legitimate instantaneous setting; an absent dwell is refused
  (`InvalidDataException`) naming every missing key. The LVRT and vector-shift stages are instantaneous by definition
  and have no dwell key.
- **Frequency settings move with the nominal.** `settingsNominalHz` (`AssetParams.SettingsNominalHz`) is the nominal the
  class's `ufTripHz`, `ofTripHz` and `lfddStageHz` are written for; absent, it is the GB 50 Hz
  (`AssetParamDefaults.ProtectionSettingsNominalHz`). On a system at another nominal (the fleet passes the model's
  nominal) each of these settings becomes `systemNominal + (setting - settingsNominalHz)`: a GB 48.8 Hz LFDD stage
  operates at 58.8 Hz on a 60 Hz case. At equal nominals the setting is used exactly as written.
- **Frequency settings must be plausible.** A UF or LFDD setting at or above its settings nominal, an OF setting at or
  below it, a setting more than 10 Hz from it on its own side (`AssetClassSupport.MaxFrequencySettingDistanceHz`), a
  non-finite setting, or a `settingsNominalHz` that is not a finite frequency above 0, is refused by name, at library
  load (`AssetClassSupport.ProtectionFrequencyProblems`) and again when a class built in code reaches
  `ProtectionController`. A setting written for a 60 Hz system must declare `settingsNominalHz` 60.

| Key | Source symbol | Stage built | Quantity tested |
|---|---|---|---|
| `rocofTripHzPerS`, `rocofTripConfirmS` | `RocofTripHzPerS`, `RocofTripConfirmS` | trip, above threshold, dwell = confirm (required) | abs(RoCoF) x uplift |
| `dfDtTripHzPerS`, `dfDtTripDwellS` | `DfDtTripHzPerS`, `DfDtTripDwellS` | trip, above | abs(RoCoF) x uplift |
| `localRocofUpliftFactor` | `LocalRocofUpliftFactor` | multiplier on the RoCoF stages (fallback 1.0) | |
| `ufTripHz`, `ufTripDwellS` | `UfTripHz`, `UfTripDwellS` | trip, below (setting moved to the system nominal) | delayed frequency |
| `ofTripHz`, `ofTripDwellS` | `OfTripHz`, `OfTripDwellS` | trip, above (setting moved to the system nominal) | delayed frequency |
| `uvTripPu`, `uvTripDwellS` | `UvTripPu`, `UvTripDwellS` | trip, below | local voltage |
| `ovTripPu`, `ovTripDwellS` | `OvTripPu`, `OvTripDwellS` | trip, above | local voltage |
| `lvrtVoltagePu` | `LvrtVoltagePu` | trip, below, dwell 0.0; only when above 0 | local voltage |
| `overloadTripFraction`, `overloadTripDwellS` | `OverloadTripFraction`, `OverloadTripDwellS` | trip, above | loading fraction |
| `vectorShiftTripDeg` | `VectorShiftTripDeg` | trip, above, dwell 0.0; only when finite | abs(phase step) |
| `lfddStageHz`, `lfddDwellS`, `lfddBlockMw` | `LfddStageHz`, `LfddDwellS`, `LfddBlockMw` | shed `lfddBlockMw` x demand scale of demand, below (setting moved to the system nominal) | delayed frequency |
| `settingsNominalHz` | `SettingsNominalHz` | the nominal the frequency settings are written for (default 50) | |
| `detectionLatencyS` | `DetectionLatencyS` | measurement delay for the frequency, RoCoF and phase | |

An LFDD stage is always a demand shed, whatever the recloser flag says. An LFDD block is a share of the demand on the
feeders it disconnects (Grid Code CC.A.5.5.1): `ProtectionController.SetDemandScale(factor)` tells the device the
demand now running as a fraction of the base case, and a shed stage then disconnects `lfddBlockMw * factor`
(remembered per stage, so a reclose reconnects the same MW). The live loop sets the factor every tick from the
load-scaled operating point; every batch study leaves it at 1.0. An infeed trip keeps its capacity. A stage's MW is
its `ActionMw` when positive, else the instance `capacityMw`. A class that sets several trip keys loses its `capacityMw` once, however many stages
fire.

## Algorithm: where each parameter acts

All equations are as implemented. `rated` is the generator `MBase` in MW, `pg` its dispatched `Pg`.

`AssetDynamicsFleet.StepCoi` passes a local voltage of 1.0 pu and a loading of 0.0 unless its `voltageOf` and
`loadingOf` suppliers are given, and the scripted `trip --asset-dynamics` run gives neither. On that path the
`lvrtVoltagePu` trips, `uvTripPu`, `ovTripPu` and `overloadTripFraction` therefore cannot fire; `LiveSim` supplies
both after each power-flow solve ([ch. 15](<0015 Protections.md>)).

### Grid-following inverter

Per substep, with `dt` the substep and `f_meas`, `rocof_meas` the local frequency and RoCoF read from the measurement
delay buffer at age `detectionLatencyS`:

```
protect:   over   = abs(rocof_meas) * localRocofUpliftFactor > rocofTripHzPerS
           dwell  = over ? dwell + dt : 0
           trip   = over and dwell >= rocofTripConfirmS
                    or abs(phaseStep) > vectorShiftTripDeg      (phase change over max(dt, 0.02 s))
                    or (lvrtVoltagePu > 0 and V_local < lvrtVoltagePu)
           on trip: output 0, infeed lost = pg, latched

compute:   armed when abs(f_meas - f0) > deadbandHz, at t + computeLatencyS
           capUp   = headroomUpFraction   * rated   (min with DC source headroom)
           capDown = headroomDownFraction * rated   (min with DC source headroom)
           gain    = droopGainMwPerHzPerMw * rated
           fullHz  = gain > 0 ? max(capUp, capDown) / gain : 0.5
           droop   = FastResponseTarget(df, max(capUp, capDown), deadbandHz, fullHz)
                   = clamp(-(max(capUp, capDown) / fullHz) * df, -cap, +cap), 0 inside the deadband
           target  = clamp(droop - rocofGainMwsPerHz * rocof_meas, -capDown, capUp)

actuate:   ramped = clamp(target, p - slewDown*rated*dt, p + slewUp*rated*dt)   (a zero slew is no limit)
           p     += (ramped - p) / max(dt, actuateTauS) * dt
           then the DC source draws p and returns what it delivered
```

The droop leg disarms again once the measured frequency has stayed inside the deadband for `computeLatencyS`
(counted in whole substeps), so every later excursion meets the compute latency again. The uplift multiplies the RoCoF
the trip tests and nothing else: the droop and df/dt legs act on the delayed, unuplifted value.

**Dispatch.** The infeed a trip books is the unit's dispatched output. `AssetDynamicsFleet.SetDispatch(model)` hands
every generator-bound asset its generator's `Pg` in the operating point now running; the live loop calls it every tick
with the load-scaled, re-balanced model, so a trip books the output actually lost. It refuses an operating point with
a different generator count or a bound generator at another bus (`ArgumentException`). Placed protection devices keep
their capacity. For the bundled wind class, `droopGainMwPerHzPerMw` 2.0 and `headroomUpFraction` 0.10 give
`fullHz = 0.10 * rated / (2.0 * rated) = 0.05 Hz`: the droop leg reaches full output at 0.05 Hz deviation.

### Grid-forming inverter

```
trip:     abs(rocof_local) * localRocofUpliftFactor > rocofTripHzPerS for rocofTripConfirmS,
          or (lvrtVoltagePu > 0 and V_local < lvrtVoltagePu)
target  = clamp(-synInertiaMwsPerHz * rocof_local - dampingMwPerHz * dfActive, -capDown, capUp)
dfActive = df when abs(df) > deadbandHz, else 0
p      += (target - p) / max(dt, actuateTauS) * dt
```

`synInertiaMwsPerHz` is a power gain on df/dt. It adds no energy to the system's stored rotational energy `E`
([ch. 5](<0005 Frequency dynamics.md>)).

### DC source

With `capacityMwh` at or below 0 there is no store. With a `batteryChemistry` code in 1 to 6 the store is a `PackModel`
sized from `capacityMwh` and `dcVoltageV` behind a converter of efficiency `converterEfficiency`
([ch. 27](<0027 Battery energy storage.md>)); a reset restores the pack in place from a snapshot that keeps its
ageing state, so the pack ages across resets. Otherwise it is the `SocBucket`:

```
soc   -= p * dt / 3600 / capacityMwh          (then clamped to [0, 1])
headroom up   = 0 when soc <= socMin, else unbounded
headroom down = 0 when soc >= socMax, else unbounded
```

### Protection stage

Each stage tests its quantity against its threshold; an excursion that lasts `dwell` seconds fires the stage once
(`ProtectionEvaluator.Step`). With `localRocofUpliftFactor` u and threshold T, a RoCoF stage fires when
`abs(RoCoF) * u > T` for the dwell, so the effective threshold on the COI RoCoF is `T / u`.

### Transformer and line

```
transformer:  err   = V_ctrl - targetVpu
              out of band when abs(err) > tapDeadbandPu; time accumulates, resets inside the band
              step when time >= (first step ? initialTapDelayS : interTapDelayS):
                  tap = clamp(tap -/+ tapStepPu, minTap, maxTap)
                  direction: tapped (From) end controlled: high V lowers the tap
                             untapped (To) end controlled:  high V raises the tap
              thermal += (max(loading, ambientLoadingFraction) - thermal) / max(dt, 60*thermalTauMin) * dt
              derate   = derateAtFullThermal * clamp(thermal, 0, 1)
line:         thermal += (max(loading^2, ambientLoadingFraction) - thermal) / max(dt, 60*thermalTauMin) * dt
              derate   = derateAtFullThermal * clamp(thermal, 0, 1)
```

The tap starts at the bound branch's own `TapRatio`; a branch tap outside `[minTap, maxTap]` throws
`ArgumentOutOfRangeException` at build. `PassivePlantFleet.ApplyTo` sets the branch `TapRatio` to the tap and the
branch rating to `baseRating * (1 - derate)`, always from the original rating, so re-applying an update does not
compound. A transformer whose controlled bus is generator-regulated (PV or slack in the tick's solved bus types,
`PowerFlowResult.SolvedBusTypes`) holds its tap and only derates. The fleet runs per tick when
`DynamicsConfig.EnablePassivePlant` is set (`LiveSim`) or `gda-replay --passive-plant` is given; off, the loops are
bit-identical to a model with nothing bound.

### Quantities with no source

These have no value in any lake product or standard, so they stay placeholders or are swept:

- **Inverter internal control loops.** Droop and df/dt gains, detection, compute and actuate latencies, PLL and
  current-loop time constants, fast-slew MW/s, LVRT/FRT behaviour are vendor-proprietary.
- **BESS `capacityMwh` and duration.** The MW sizing is grounded (REPD operational batteries: 171 sites, 4,755 MW,
  median 23 MW); the duration is not.
- **The legacy-versus-upgraded embedded-generation fraction.** The relay thresholds are recorded; no register says how
  much embedded generation was upgraded under ALoMCP. It is the highest-leverage knob of the RoCoF-trip cascade, which is
  why a real-fleet claim is a parameter-sweep envelope (`AssetEnvelope`, `AssetEnvelopeResult.CascadeIsPossible`)
  and not a point prediction.
- **OLTC mechanical delay and transformer or cable thermal time constants.** The lake has no tap-position-against-time
  channel and no temperature series (`DataSources/UkPowerNetworks/Processors/detect_tap_changers.py`). Grounded ratings
  give steady-state headroom only.
- **Fault level and grid stiffness.** No fault-level product exists in the lake; the local-stiffness proxy stays a placeholder.
- **Transformer MW and MVAr loading.** There is no `transformer_flows` product, only a BSP power-factor summary (mean
  0.95, median 0.98, so MVA is close to MW at most BSPs).
- **Inter-domain propagation delay.** `Derived/propagation_delays` is synthetic (`is_synthetic_speed=True`, literature
  band 500 to 1500 km/s, 5 to 8 ms per corridor).
- **Protection settings with no operational data.** Recloser, auto-reclose and breaker operation (only customer-outage
  counts exist), under- and over-voltage (no measured GB voltage series), thermal and reactive overload, and fault level.
  The recloser mechanism is modelled in full; its settings are assumed.
- **Impedance-screen converter parameters.** `pllBandwidthHz`, `pllDampingRatio`, `currentLoopBandwidthHz`,
  `virtualReactancePu` and `powerLoopBandwidthHz` are set by no bundled class. The impedance screen takes the
  `ConverterDefaults` literature values (PLL bandwidth 20 Hz, the one default EMT, impedance and small-signal share; damping 0.707) and labels the result
  `CuratedPlaceholder`; it labels it `Recorded` only when the bandwidth came from a class whose provenance for
  `pllBandwidthHz` is `Recorded` or `DerivedFromRecorded` and no override was typed. The same rule applies to
  `virtualReactancePu`.

The parameter followed here is `rocofTripHzPerS = 0.125` of the class `prot-lom-legacy` in
`data/gb-synthetic/asset-classes.json`. The captures are in `docs/_captures/asset-grounding/`. The outputs carry no timings;
every number in them is a simulation result.

**1. The file.** The class is `kind: protection`, `params` `rocofTripHzPerS` 0.125, `rocofTripConfirmS` 0.0,
`localRocofUpliftFactor` 1.16. Its provenance entries are `Recorded` for `rocofTripHzPerS` (legacy GB LoM setting, GDA
`rocof_events` relay_legacy grade) and `DerivedFromRecorded` for `localRocofUpliftFactor` (sub-cycle local over COI,
1.16). `rocofTripConfirmS` has no entry, so it resolves to the synthetic `CuratedPlaceholder`. `protections.json`
places the class as `embedded-dg-lom` at bus 1 with `capacityMw` 800.

**2. The loader.** `AssetClassSupport.AcceptedKeys(Protection)` contains all three keys, so step 3 passes. The class has
no `CuratedPlaceholder` entry, so step 4 has nothing to check for it. The instance references a class of kind
`protection`, so step 6 passes. A broken file is refused before any run; for example a `dispatchRampMwPerMin` key:

```
$ gridsim trip results/asset-grounding/ramp-key --asset-dynamics on

  asset class 'gfl-wind-2024' sets 'dispatchRampMwPerMin': no controller reads it: the inverter controllers model the frequency response about a fixed dispatch, so there is no dispatch setpoint to ramp (the fast response is already rate-limited by fastSlewUp/DownMwPerSPerMw). The bundled values were an observed fleet ramp band, recorded in docs/technical/0013 Asset-dynamics data grounding.md. Remove the key.
[exit 1]
```

and a placeholder note stripped of its token:

```
$ gridsim trip results/asset-grounding/no-verify --asset-dynamics on
error: cannot load case folder 'results/asset-grounding/no-verify': Invalid asset-classes.json:
  asset class 'gfl-wind-2024' parameter '_default' is CuratedPlaceholder but its note lacks the literal [VERIFY] token.
[exit 1]
```

Each broken case is a copy of `data/gb-synthetic` with one edit: `ramp-key` adds `"dispatchRampMwPerMin": 30` to the
`params` of `gfl-wind-2024`; `no-verify` replaces the note of the `_default` entry of `gfl-wind-2024` with text that
lacks the token. The folders are under the git-ignored `results/`.

**3. The controller.** `ProtectionController.BuildStages` finds `rocofTripHzPerS` and adds one stage: quantity RoCoF,
sense above, threshold 0.125, dwell `rocofTripConfirmS` (0.0), action trip infeed, uplift 1.16. The stage fires when

```
abs(RoCoF) * 1.16 > 0.125        that is   abs(RoCoF) > 0.125 / 1.16 = 0.1078 Hz/s
```

and a zero dwell fires on the first substep over the threshold. The trip removes the instance `capacityMw`, 800 MW, once.

**4. The captured run.** `gridsim trip data/gb-synthetic --asset-dynamics on` trips Hinkley Point Nuclear (2880 MW) at
t = 1 s. Without the fleet the peak RoCoF is -0.453 Hz/s, 4.2 times the effective threshold of 0.1078 Hz/s (indicative: the

## Limits

- The bundled provenance blocks are not checked against the sources: `ValidateProvenance` enforces `[VERIFY]` on placeholders only, and no test compares a `Recorded` value with `FrequencyLimits` or with the GDA lake.
- In `gb-synthetic` the grid-following wind and solar `rocofTripConfirmS` (0.5 s) and the legacy `rocofTripConfirmS` (0.0 s) carry no `Recorded` entry, although `gb-full` and `dg-alomcp` cite them, and `gb-synthetic` sets no `localRocofUpliftFactor` on its inverter classes.
- The vector-shift trip is a phase-change proxy, not a phase-jump detector: phase is integrated smoothly (`phase += 360 * (f - f0) * dt`), so the relay compares the accumulated change over `max(dt, 0.02 s)` with `vectorShiftTripDeg` and fires on a sustained frequency offset, not on a discrete angle step.
- The depth of the 2019-08-09 cascade is not predicted: the embedded volume that trips is `[VERIFY]` and swept, the nadir is a strong function of it, and the result is tagged `UnvalidatedAtScale`; a blind cross-event test needs a second GB cascade event, and none exists.
- Every inverter control constant, the BESS duration, the OLTC delays, the thermal time constants, fault level and the legacy-versus-upgraded embedded-generation fraction are placeholders or swept, not recorded (listed under "Quantities with no source").
- No synchronous-machine class exists: a machine trip must drop `E` live, and no controller does so.
- The GDA lake files cited here are outside this repository, so their values cannot be re-derived from it.
