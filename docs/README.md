# GridSim documentation

| Folder | What it holds |
|---|---|
| [`manual/`](<manual/0000 Contents.md>) | The user manual: installing, loading networks, running solves and studies, the apps, the CLI reference. |
| [`technical/`](technical/) | The technical reference: the mathematics as implemented, parameters, invariants, file and wire formats, architecture. |
| [`_captures/`](_captures/) | Worked examples: the exact command lines and outputs the manuals quote, regenerated by `tools/docs/capture.ps1`. |
| [`validation/`](validation/) | Validation evidence: cross-validation against other tools, the solver validation report, GB event reconstructions and studies. |
| [`assurance/`](assurance/) | Security and assurance notes: risk register, incident response, SBOM and secrets handling, standards mappings. |
| [`developer/`](developer/) | Building and running GridSim yourself: the documentation style guide, deployment examples, benchmarks and performance baselines, case libraries, the solve export format. |
| [`reference/`](reference/) | The cited public reference documents, checked by `reference/MANIFEST.sha256`. |
| [`screenshots/`](screenshots/) | Screenshots used by the manuals. |
| [`Public/`](Public/README.md) | An optional submodule of public GB grid documents (not downloaded by a normal clone). |

The deterministic maths library is summarised in [`MATH.md`](../MATH.md) and specified in
[technical ch. 38](<technical/0038 Deterministic mathematics.md>).

The release notes for this build are in [`RC1.md`](../RC1.md); the change history is in [`CHANGELOG.md`](../CHANGELOG.md).
