# GridSim documentation

GridSim is a physics-first power-grid simulator in C# on .NET 10. **Nothing in GridSim is validated, at any scale.**
Its author is an HPC engineer whose role is the code; the documents here record what the code does, the tests that pin
it and how it compares with independent tools, so that you can judge it yourself. The
[project README](../README.md) states the position in full. Results and bug reports are welcome at
mark@gridsimdigitaltwin.co.uk.

| Folder | What it holds |
|---|---|
| [`manual/`](<manual/0000 Contents.md>) | The user manual: installing, loading networks, running solves and studies, the apps, the CLI reference. |
| [`technical/`](technical/) | The technical reference: the mathematics as implemented, parameters, invariants, file and wire formats, architecture. |
| [`_captures/`](_captures/) | Worked examples: the exact command lines and outputs the manuals quote, regenerated by `tools/docs/capture.ps1`. |
| [`validation/`](validation/) | Cross-check evidence: agreement with independent tools and published solutions, GB event reconstructions and studies. None of it validates GridSim against a real power system. |
| [`assurance/`](assurance/) | Security and assurance notes: risk register, incident response, SBOM and secrets handling, standards mappings. |
| [`developer/`](developer/) | Building and running GridSim yourself: the documentation style guide, deployment examples, benchmarks and performance baselines, case libraries, the solve export format. |
| [`reference/`](reference/) | The cited public reference documents, checked by `reference/MANIFEST.sha256`, and [`paywalls.md`](reference/paywalls.md): the `[VERIFY]` values whose settling document is paywalled. |
| [`releases/`](releases/) | Release-candidate addenda (RC2 additions). The release records `RC1.md`, `RC3.md` and `RC4.md` stay at the repository root. |
| [`screenshots/`](screenshots/) | Screenshots used by the manuals. |
| [`archive/`](archive/) | Three 2.1.030 assessments (7 November 2026), kept unedited as a historical record; not current. |
| [`brand/`](brand/README.md) | The brand kit: logo and avatar SVGs and the brand sheet (social preview source). |
| [`Public/`](Public/README.md) | An optional submodule of public GB grid documents (not downloaded by a normal clone). |
